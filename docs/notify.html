알림 받기

새 브리핑이 올라오면 바로 알려드립니다
✓ 완전 무료 · 앱 설치 불필요 · 회원가입 없음
아래 버튼을 누르면, 새 브리핑이 올라올 때 이 기기로 알림이 옵니다. 다른 앱을 깔거나 이 사이트에 가입할 필요가 없습니다.
iPhone·iPad를 쓰신다면 — Safari에서 공유 → 홈 화면에 추가로 설치한 뒤, 홈 화면 아이콘으로 열어서 켜야 알림이 옵니다(iOS 16.4 이상). 애플 정책상 그렇습니다.
이 브라우저는 웹 알림을 지원하지 않습니다. Chrome·Edge·Android Chrome에서 이 페이지를 열면 알림을 켤 수 있습니다.
iPhone·iPad라면 Safari에서 공유 → 홈 화면에 추가로 설치한 뒤, 홈 화면 아이콘으로 이 페이지를 열어주세요(iOS 16.4 이상). 일반 Safari 탭에서는 애플 정책상 알림을 켤 수 없습니다.
